# Test Coverage Report

## Summary

The Stellar workspace includes unit, integration, audit regression, property-style, upgrade authorization, and SAC compatibility tests. CI also defines coverage gates through `cargo tarpaulin` for the main Stellar contracts.

This report is a reproducible coverage inventory, not a committed HTML coverage artifact. HTML coverage reports are generated by CI and uploaded as workflow artifacts from `.github/workflows/coverage.yml`.

## Commands for auditors

Run all Stellar tests:

```bash
cd stellar
cargo test --workspace
```

Run only in-scope package tests:

```bash
cd stellar
cargo test -p stealth-announcer
cargo test -p stealth-registry
cargo test -p stealth-sender
cargo test -p wraith-names
```

Run upgrade authorization tests:

```bash
cd stellar
cargo test upgrade_auth --workspace
```

Run coverage locally:

```bash
cd stellar
cargo install cargo-tarpaulin
cargo tarpaulin -p stealth-announcer --out Html --output-dir coverage/stealth-announcer --fail-under 90
cargo tarpaulin -p stealth-registry --out Html --output-dir coverage/stealth-registry --fail-under 90
cargo tarpaulin -p stealth-sender --out Html --output-dir coverage/stealth-sender --fail-under 90
cargo tarpaulin -p wraith-names --out Html --output-dir coverage/wraith-names --fail-under 80
```
