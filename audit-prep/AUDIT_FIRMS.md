This document provides a shortlist of recommended security audit firms for the Wraith Protocol Stellar contracts. Firms are categorized by tier based on reputation, Stellar/Soroban experience, and pricing.

## Audit Proposal Template

When contacting firms, use this template:

```
Subject: Security Audit Request - Wraith Protocol Stellar Contracts

Hi [Firm Name],

We are seeking a security audit for Wraith Protocol's Stellar smart contracts. 
Below is the project summary:

**Project:** Wraith Protocol (Stealth address infrastructure)
**Platform:** Stellar (Soroban smart contracts)
**Language:** Rust
**Scope:** 4 core contracts (~850 LOC) + 2 optional (~450 LOC)
**Timeline:** Audit needed by [DATE]
**Budget:** $[AMOUNT] (flexible based on scope)

**Contracts:**
1. stealth-announcer (~100 LOC) - Event emitter
2. stealth-registry (~150 LOC) - Meta-address registry
3. stealth-sender (~200 LOC) - Atomic asset transfer + announcement
4. wraith-names (~400 LOC) - Name resolution with guardian recovery

**Audit Package:** Available at [LINK TO GITHUB REPO]/audit-prep/
- Scope definition
- Threat model (STRIDE)
- Internal audit reports
- Test coverage report
- Reproducible build instructions

**Questions:**
1. Do you have Soroban/Rust auditing experience?
2. What is your estimated timeline?
3. What is your pricing for this scope?
4. Can you provide references for similar audits?

Please let us know if you need additional information.

Best regards,
[Your Name]
Wraith Protocol Security Team
security@usewraith.xyz
```
